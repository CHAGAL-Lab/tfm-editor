# TFM Editor

An unofficial editor for Teamfight Manager saves and game files. You can change a player's stars, age and traits, and your team's gold. It runs on Windows and Linux (Proton) and needs no installation.

## Download

Download the [latest release](https://github.com/CHAGAL-Lab/tfm-editor/releases/latest) for your system (Windows or Linux), extract it and run tfm-editor.

- Extract it somewhere you can write to, such as the desktop or the documents folder, because backups are saved next to it.
- The program is not signed, so Windows may show a security warning.

## Advanced features

The Advanced tab changes game files, not saves, so it applies to every save.

- Growth curve: edit the table that decides how much players grow as they age.
- Raise star count: raises the number of stars the game supports from 3 up to 9. Do this first if you want players with 4 or more stars.
- Hidden traits: give a player traits that the game screen does not show (up to 3).

## Language

The program is available in Korean and English. Pick `ko` or `en` in the top right corner; the choice is remembered. The first time, it follows your computer's language. Trait names and descriptions switch too.

## Good to know

- Changes can only be made while the game is closed.
- Before changing anything, the program copies the save to the backups folder automatically. You can go back with Restore backup in the program.
- Values you can enter: stars from 0 up to the number the game supports, age 17-40, gold 0-9,999,999.
- If Steam verifies or updates the game files, whatever you changed with the Advanced features is reset to the original.
